## How to use them well
1. Fetch the filter page for the pattern you picked; list 5–8 candidate examples with their site category.
2. Prefer examples from the same kind of product (SaaS, fintech, dev tool, agency) and the same tone.
3. If a browser tool is available, open 2–4 entries and look at desktop and mobile; otherwise ask the user to glance at the links you list.
4. Write down what you're taking from each (e.g. "Cloudflare: mega menu grouped by product with one-line descriptions"), then design your own version.
5. Never copy logos, illustrations, copy text or brand colours; borrow structure, proportion and interaction ideas.
