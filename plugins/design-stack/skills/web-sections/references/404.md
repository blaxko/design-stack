# 404 and error pages

Taxonomy from 404s.design. Live examples: `https://www.404s.design/` (entries at `/sites/<slug>`; filters aren't linkable, so describe the style you want and scan the grid).

**Styles:** 3D, Bold, Brutalist, Colorful, Dark, Editorial, Glitchy, Hand-drawn, Illustrative, Large type, Light, Minimal, Photographic, Playful, Retro, Typographic.
**Interaction:** Animated, Custom cursor, Game, Hover effects, Interactive, Scroll-driven.
**Industry fit:** Agency/studio and portfolio can go wild (games, glitch, cursor play); Tech/SaaS usually large type + one clever touch; Fintech, government and non-profit stay calm and reassuring.

## Must have (recovery first, personality second)
- Plain statement: "This page doesn't exist" (or "moved"), not just "404".
- A way forward: primary button to home or the app, plus 2–4 likely destinations (docs, pricing, search, status).
- Search box on content-heavy sites.
- Keep the site's navbar and footer so the visitor isn't stranded.
- Return a real 404 HTTP status; `noindex`; log the missing URL so broken links get fixed.
- Works with JS disabled and with reduced motion; any game or animation is optional, never blocking the way out.

## Taste notes
- One idea, executed well: a big typographic "404" with a subtle interaction, a short on-brand line, or a tiny game. Not all three.
- Copy can be witty, but the recovery path must be obvious in under two seconds.
- Also design the 500 / maintenance page in the same style: what happened, whether data is safe, what to do, status link.
