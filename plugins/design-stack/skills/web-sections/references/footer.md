# Footers

Styles from footer.design (800+ examples). Live examples per style: `https://www.footer.design/styles/<slug>`; all: `https://www.footer.design/browse`.

| Style (slug) | Character | Fits |
|---|---|---|
| **Typographic** (`typographic`) / **Large type** (`large-type`) | Oversized wordmark or a closing line spanning the width | Brand-led products, agencies, confident launches |
| **Small type** (`small-type`) | Quiet, dense, utilitarian | Apps, dev tools, docs |
| **Grid** (`grid`) | Link columns in a strict grid | Sites with many pages |
| **Cards** (`cards`) | Blocks for newsletter, contact, social | Content and community sites |
| **Illustrative** (`illustrative`) | A drawing or scene closes the page | Brands with an illustration system |
| **Animated** (`animated`) | Marquee, reveal, interactive mark | Portfolios, playful brands (respect reduced motion) |
| **Dark** / **Bright** / **Flat** / **Bold** (`dark`, `bright`, `flat`, `bold`) | Colour treatment | Pick to contrast with the last section above it |

## Must have
- Wordmark/logo + one-line description of what the product is.
- Link columns grouped by intent (Product, Developers, Company, Legal), 3–6 links each, real links only.
- Contact route (email or form), socials as icons with accessible names.
- Legal: copyright year, privacy, terms; status/network badge if relevant.
- `footer` landmark; link contrast ≥ 4.5:1; tap targets spaced on mobile; columns stack to 2-up then 1-up.

## Taste notes
- The footer is the last impression: a closing statement or CTA line ("Start in five minutes →") above the links works better than a bare sitemap.
- Optional: a newsletter field, a theme switch, a small "back to top".
- Don't repeat the whole navbar plus everything else; curate.
