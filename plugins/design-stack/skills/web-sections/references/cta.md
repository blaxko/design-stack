# Calls to action

Types from cta.gallery. Live examples per type: `https://www.cta.gallery/categories/<slug>`; writing tips page: `https://www.cta.gallery/cta-tips`.

| Type (slug) | Use for | Pattern |
|---|---|---|
| **Button** (`button`) | Primary next step anywhere | Verb-first label + optional supporting line or reassurance under it |
| **Call-to-buy** (`call-to-buy`) | Store, checkout, product page | Price + key benefit + button; trust marks (returns, secure payment) nearby |
| **Download** (`download`) | Apps, files, extensions | Platform-detecting primary button, other platforms as links, QR for desktop→mobile |
| **Form** (`form`) | Waitlist, demo request, contact | Fewest fields possible, inline validation, clear success state |
| **Modal / pop-up** (`modal-pop-up`) | Exit intent, timed offers | Use sparingly; easy dismiss, no dark patterns, never on first paint |
| **Navigation** (`navigation`) | CTA inside the navbar | One prominent button, contrasting style, stays visible |
| **Newsletter** (`newsletter`) | Content, community | Say what they get and how often; one field + button; privacy note |
| **Pricing / subscription** (`pricing`) | Plan selection | Highlight one plan, annual/monthly toggle, the CTA names the plan |

## Writing rules (from CTA tips, applied)
- **Say exactly what happens:** "Create my account", "Connect wallet", "Book a 20-min demo"; never "Submit", "Click here", "Learn more" as the main action.
- **Lead with a verb; keep it to 2–5 words.** First person ("Start my trial") often reads warmer.
- **Show the payoff and remove risk next to it:** "Free for 14 days · No card needed", "Cancel anytime", "Testnet, no real funds".
- **Urgency only when real.** Fake countdowns destroy trust.
- **Back it with a headline** that states the offer; the button completes the sentence.

## Must have
- One primary CTA per view; secondary as a text link or ghost button.
- Contrast that stands out from everything else on the page; 44px min height; visible hover, focus, pressed, loading and disabled states.
- Key CTA visible without scrolling (hero) and repeated at the end of the page.
- After click: immediate feedback (loading state), then a clear success or error state.

## Final CTA section pattern
Short headline restating the outcome + one supporting line + primary button + risk-reducer line. Optional: a product visual or a single proof point. Generous padding; often the boldest colour block on the page.
